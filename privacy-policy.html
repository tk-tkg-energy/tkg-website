PRIVACY POLICY

プライバシーポリシー

東京共同技術株式会社（以下「当社」）は、お預かりする個人情報と、当社が利用する外部サービスでの情報の扱いについて、次のとおり定めます。

01

取得する情報

当社は、お問い合わせのメールなどを通じて、氏名、会社名、メールアドレス、電話番号、お問い合わせの内容を受け取ることがあります。当社のウェブサイトには、お問い合わせフォームや、閲覧を記録する解析ツールは設けていません。

02

利用目的

受け取った情報は、お問い合わせへの回答、業務のご連絡、契約の履行のためにだけ使います。

03

第三者への提供

法令に基づく場合を除き、ご本人の同意なく第三者に提供しません。

04

安全管理

受け取った情報は、情報セキュリティ基本方針に従って管理します。

05

YouTube API サービスの利用

当社は、当社の YouTube チャンネルに自社の動画と字幕を上げるため、社内用のツールで YouTube API サービスを利用しています。このツールが扱うのは当社のチャンネルだけで、他の利用者のアカウントやデータにはアクセスせず、取得も保存もしません。ツールの許可情報（OAuth トークン）は当社の端末の中にだけ保存し、第三者に渡しません。YouTube API サービスの利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。当社のツールへの許可は、Google アカウントのセキュリティ設定 からいつでも取り消せます。

06

ウェブサイトの技術情報

当社のウェブサイトは Cloudflare のサービスで配信しており、表示の際に Google Fonts から文字の書体を読み込みます。その際、閲覧者の IP アドレスなどの技術情報がこれらの事業者に送られることがあります。当社のウェブサイト自体は Cookie を使った閲覧記録を行っていません。

07

開示・訂正・削除のご請求とお問い合わせ

ご自身の情報の開示、訂正、利用停止、削除のご請求、そのほか本ポリシーへのお問い合わせは、info@tkg-energy.com までご連絡ください。

08

改定

本ポリシーは、法令や業務の変化に合わせて改めることがあります。改めた場合は、このページでお知らせします。

English summary

Tokyo Kyodo Technology Co., Ltd. uses YouTube API Services through an internal tool that uploads our own videos and captions to our own YouTube channel. The tool accesses only our own channel. It does not access, collect, store or share any data of other YouTube users. The OAuth token for the tool is stored only on our own computer and is never shared with third parties. By using YouTube API Services, the YouTube Terms of Service and the Google Privacy Policy apply. Access granted to our tool can be revoked at any time from the Google security settings page. Our website does not use cookies for tracking. Personal information we receive by e-mail is used only to reply and to carry out our business. Contact: info@tkg-energy.com
